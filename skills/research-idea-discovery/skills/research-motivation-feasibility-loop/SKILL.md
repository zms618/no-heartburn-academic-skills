# v4.0 Motivation-Feasibility Loop

Scientific motivation and feasibility must be evaluated together.
Do not generate methods before validating problems.

Pipeline:
Scope -> Landscape -> Motivation -> Evidence -> Feasibility -> Gap -> Idea -> Method -> Validation -> Reviewer Attack.

Every idea needs:
- important problem
- evidence
- data path
- baseline
- falsification experiment.
