# Research Problem Validation v3.7

The plugin must discover problems before proposing methods.

Required flow:
Scope -> Problem Landscape -> Critical Papers -> Failure Mining -> Motivation Validation -> Gap -> Idea -> Method.

Every candidate must answer:
1. What observation motivates it?
2. Which assumption of prior work fails?
3. Why is it important?
4. What experiment can kill it?
5. Why cannot a simple baseline solve it?

Reject method-first proposals without problem evidence.
