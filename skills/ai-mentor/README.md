# AI Mentor｜科研问题随时聊

**科研中遇到问题，就和 AI 导师一起拆解。** 这是一款面向 ChatGPT 网页端的个人科研插件，帮助你讨论研究想法、文献调研、实验设计、论文写作、科研绘图、投稿准备与研究进度。它会结合你的目标和已有材料，梳理问题、指出需要核实的证据，并给出可以继续推进的下一步。

它不是自动替你做科研，也不保证每个问题都有现成答案；它的目标是让你遇到科研卡点时，有一个结构化的讨论伙伴，帮助把复杂问题变成清楚、可判断、可行动的任务。

> **在 ChatGPT 网页端作为个人插件使用，不消耗 Codex 专用额度。**

## 能帮你讨论什么？

- **研究方向与 Idea**：厘清研究问题、比较候选方向、检查核心假设与验证路径。
- **文献与证据**：梳理相关工作、比较方法与结论，区分已有证据和待验证判断。
- **实验与项目推进**：讨论实验设计、基线、消融、失败分析、项目计划与进度复盘。
- **论文写作与投稿准备**：搭建论文结构、改进论证、规划科研图表，并以审稿人视角检查薄弱之处。
- **长期科研训练**：在对话上下文和可用记忆范围内，帮助记录研究决策、未解决问题与阶段目标。

插件包内包含 Supervisor Mode、Personal PhD Advisor、Idea Evaluator、Deep Research、Paper Writer、Figure Designer、Pre-submission Reviewer 等 Skills，以及科研手册与配套参考资料。具体能力取决于 ChatGPT 当前可用的模型、文件和工具。

## 在 ChatGPT 网页端上传 ZIP 并安装

[下载 AI Mentor v1.4.0 插件 ZIP](../../downloads/ai-mentor-v1.4.0.zip)

1. 打开 ChatGPT 个人插件管理页面（从头像或设置进入“插件 / 个人插件”，也可访问 [chatgpt.com/plugins?directoryTab=personal](https://chatgpt.com/plugins?directoryTab=personal)）。
2. 点击 **添加**，选择 **上传插件压缩包**。
3. 选择 `ai-mentor-v1.4.0.zip`，等待解析后按界面提示创建或安装。
4. 在个人插件列表确认出现 **AI Mentor**，然后在新对话的工具/插件选择器中启用它。

安装后可以这样开始：

> 我最近在【研究方向/项目】上遇到一个问题：【描述问题】。请先帮我把问题拆清楚，指出需要哪些信息或证据，再和我一起确定最值得做的下一步。不要把推测说成事实。

如果页面按钮名称因产品版本而异，寻找“个人插件 → 添加 → 上传插件压缩包”入口。个人插件不会因此自动出现在公共插件目录。
